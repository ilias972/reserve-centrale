# Changelog

## v0.1.0 — 2026-11-14 (experimental)

First public experimental release.

### Available

- Item catalogue, stock balances, reservations and movement history.
- Internal requests, preparation, partial distributions and traceable corrections.
- Manually recorded supplier orders, partial receipts and exception follow-up.
- User roles, department access, dashboards, reporting and XLSX exports.
- English, French and Modern Standard Arabic interface with RTL layout.
- Local fictitious demo-data generator, consistency checks, and backup and restore tools.

This release is not a production-readiness or regulatory-compliance claim. See [Limitations](docs/LIMITATIONS.md).
