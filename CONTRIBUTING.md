# Contributing

This repository is a local publication candidate and may not yet be publicly available. Contribution terms and a public review channel must be confirmed before contributions are opened.

## Propose a change

- Describe the need and the user roles affected.
- Explain effects on reservations, the ledger, audits, idempotency, and notifications.
- Add or update isolated tests.
- Preserve the invariants documented in [Architecture](docs/ARCHITECTURE.md).
- Never include real data, secrets, private screenshots, certificates, or database files.
- Preserve third-party notices and licence obligations.

Before public contributions are accepted, the maintainers should confirm the contribution terms and licence-review process.
