# GitHub social preview

The social preview image is [`docs/screenshots/social-preview.png`](screenshots/social-preview.png), a 1280 × 640 PNG assembled from the real, fictitious-demo dashboard capture in this repository. It contains no separate logo or externally sourced illustration.

To set it for the repository, download that file and, on GitHub, open the repository **Settings → Social preview → Edit → Upload an image**. Save the change. GitHub recommends 1280 × 640 for best display and limits uploads to under 1 MB. See the [official GitHub instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

This image is supplied as a file; it is not configured automatically by this documentation change.
