# Future work ideas

These are ideas, not promised features.

1. Clarify provenance, marks, and licence scope before any distribution.
2. Validate needs and workflow differences with several organisations.
3. Decide which organisation settings, profiles, departments, and policies are shared concepts.
4. Validate regulated traceability needs with qualified stakeholders before claiming support.
5. Choose an installation model and define operational responsibilities.
6. Improve installation, upgrades, backups, and restore exercises for a dedicated instance.
7. Consider multi-tenant SaaS only if a demonstrated need and a provable isolation design exist.
